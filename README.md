Refollow

A local-first dashboard for importing and managing social-media profile links.

Features

- Import profile links from local files
- Track accounts as Not followed, Followed, or Skipped
- Search, filter, sort, and tag accounts
- Open profiles and work through them one at a time
- Use Triage mode for focused review
- Export and restore JSON backups
- Export CSV and HTML reports
- Install as a PWA on supported browsers

Privacy

Refollow runs locally in your browser.

- No backend
- No user accounts
- No analytics or tracking
- Imported files are processed locally

Your account data is stored in your browser. Export a backup if you want to move your data to another device or browser.

Run locally

No build step or dependencies are required.

python3 -m http.server 8080

Then open:

http://localhost:8080
